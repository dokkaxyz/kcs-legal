# Social video files (not part of the legal pages)

This folder lives only on the branch `claude/project-thread-mctcwc`, never on `main`, so GitHub Pages and the
privacy and terms pages are untouched. Metricool (the game's social media scheduler) needs a public link to each
video; these are the finished Reels, TikTok and YouTube Shorts files, one folder per publishing day.

Every picture is an unedited frame of the game (cropped, zoomed or slowed), the voice is a text-to-speech narrator,
and the source script is `tools/store/sosyal_reels.py` in the game's repository.
